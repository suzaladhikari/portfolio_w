Building a Transformer From Scratch: What Actually Makes a Difference?

A comparison of the transformer variants I implemented while building zalGPT, looking at how architectural changes such as RoPE, RMSNorm, and SwiGLU affect training behavior on TinyStories.

PyTorch RoPE RMSNorm SwiGLU TinyStories

While building zalGPT, I wanted to understand modern transformer components by implementing them directly rather than treating them as black boxes. I started with a small decoder-only transformer and then changed individual parts of the architecture to see what actually affected training.

The baseline

The baseline model uses token embeddings, causal multi-head self-attention, residual connections, normalization, a feed-forward network, and a final linear layer for next-token prediction. All versions are trained on TinyStories so that the architectural changes can be compared under the same type of data.

Adding RoPE

Rotary Positional Embeddings apply position-dependent rotations directly to the query and key vectors inside attention. Instead of learning a separate positional embedding table, positional information becomes part of the attention computation itself.

Replacing LayerNorm with RMSNorm

RMSNorm removes mean-centering and normalizes activations using their root-mean-square magnitude. It is a simpler normalization method that is widely used in modern language models, so I wanted to compare its training behavior directly with the baseline implementation.

Replacing the feed-forward network with SwiGLU

SwiGLU changes the standard feed-forward block by introducing a gated pathway using the SiLU activation. This gives the model a learned mechanism for controlling which transformed features are allowed through the feed-forward layer.

Experiment goal: keep the training setup as consistent as possible and compare the loss curves of the different transformer variants rather than relying only on architectural intuition.

Comparing the training curves

The interesting part is that the loss curves can look almost identical when plotted on the same full-scale graph. Small differences become easier to inspect by zooming the y-axis or plotting the loss difference relative to a baseline model.

What I learned

Building each component manually made the differences between these architectures much clearer. RoPE changes how position enters attention, RMSNorm changes how hidden states are normalized, and SwiGLU changes the structure of the feed-forward network. Even when the final loss differences are small, implementing and testing each component makes it much easier to understand why modern LLM architectures are designed the way they are.
